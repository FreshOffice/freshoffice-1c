# Обмен 1С с FreshOffice CRM

Обработка **FreshOfficeCRM.epf** переносит данные между 1С:Предприятием 8.3 и FreshOffice CRM: контрагентов, номенклатуру, остатки, документы и оплаты.

📖 **Подробная инструкция:** [help.freshoffice.ru — 1С:Предприятие](https://help.freshoffice.ru/integration/1c.html)

## Скачать

Последняя версия — в разделе **[Releases](../../releases/latest)**: файл `FreshOfficeCRM.epf`.

## Что умеет

| Что | Куда |
|---|---|
| Контрагенты: создание и обновление компаний с реквизитами, телефонами, email и контактными лицами | 1С → CRM |
| Контрагенты: создание контрагентов из компаний CRM | CRM → 1С |
| Номенклатура: группы, цены, НДС, единицы измерения | 1С → CRM |
| Остатки товаров (если в CRM выключен режим «Склад») | 1С → CRM |
| Счета, накладные и акты со строками | 1С → CRM |
| Оплаты (банк и касса) со связью со счетом | 1С → CRM |
| Счета и акты из CRM: счет на оплату и реализация (услуги), без проведения | CRM → 1С |

Перед созданием обработка ищет запись на другой стороне по коду 1С и ИНН/КПП, чтобы не создавать дубли. Если однозначно найти не удалось, строка помечается «[РЕШИТЬ]» и ждет вашего решения. Найденные записи без вашего согласия не меняются, ничего не удаляется. Перед массовой выгрузкой обработка показывает, сколько записей будет создано и обновлено, и спрашивает подтверждение.

## Требования

- **Конфигурация:** 1С:Бухгалтерия предприятия 3.0. Поддержка УТ 11, КА 2 и УНФ — в разработке.
- **Платформа:** 1С:Предприятие 8.3.27 или новее.
- **CRM:** FreshOffice CRM с доступом к API и токен API: в CRM «Настройка → API».

## Как начать

1. Скачайте `FreshOfficeCRM.epf` из [Releases](../../releases/latest).
2. Откройте обработку в 1С одним из способов:
   - **разово:** «Файл → Открыть» → выберите файл;
   - **постоянно, как дополнительную обработку:** «Администрирование → Печатные формы, отчеты и обработки» → включите «Дополнительные отчеты и обработки» → откройте этот список → «Добавить из файла…». В карточке укажите «Размещение» (раздел, где появится команда) и запишите. Так обработку видят и другие пользователи, а длинные операции идут в фоне с окном ожидания.
   - **1С:Фреш:** обработку публикует ваша обслуживающая организация (сотрудник со статусом «Разработчик дополнительных отчетов и обработок»), после проверки в 1С. Порядок и образец письма — в [справке](https://help.freshoffice.ru/integration/1c/connect.html#fresh).
3. Вкладка **«Подключение»:** вставьте токен API и нажмите **«Проверить связь»**. Если хотите, отметьте «Запомнить токен»: он сохранится только для вашего пользователя 1С.
4. Выберите вкладку нужного обмена, нажмите **«Заполнить»** (или «Получить из CRM»), проверьте отметки и нажмите **«Выгрузить в CRM»** (или «Загрузить в 1С»).

**Совет:** первый раз попробуйте на копии базы и на 2–3 записях. Все действия видны в журнале внизу формы.
